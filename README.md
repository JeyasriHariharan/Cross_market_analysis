# Cross-Market Analysis: Crypto, Oil & Stocks

## 📌 Project Overview

This project performs a cross-market analysis of **Cryptocurrency, Oil and Stock Market indices**.

The main purpose of this project is to compare the performance and trends of cryptocurrencies with traditional financial assets such as **WTI Crude Oil, S&P 500, NASDAQ and NIFTY**.

The project uses **Python, SQL and Streamlit** to collect, store, analyse and visualize financial market data.

## 🎯 Project Objective

The main objectives of this project are:

* Analyse cryptocurrency market data.
* Analyse WTI crude oil prices.
* Analyse stock market indices.
* Compare crypto with traditional financial assets.
* Identify price trends and patterns.
* Perform cross-market analysis using SQL.
* Present the analysis through an interactive Streamlit dashboard.

## 🗂️ Data Sources

The project uses data from different sources:

* **CoinGecko API** – Cryptocurrency data
* **Yahoo Finance API** – Stock market data
* **WTI Oil Price Dataset** – Crude oil price data

## 🔄 Project Workflow

The project follows this workflow:

**Data Collection → Data Cleaning → Database Storage → SQL Analysis → Visualization → Streamlit Dashboard**

### 1. Data Collection

Financial market data is collected from APIs and datasets.

### 2. Data Cleaning

The collected data is cleaned and prepared for analysis using Python and Pandas.

### 3. Database Storage

The data is stored in a relational SQLite database using separate tables for cryptocurrency, oil and stock data.

### 4. SQL Analysis

SQL queries are used to analyse the data and compare different financial markets.

### 5. Visualization

The analysed data is presented using charts and tables.

### 6. Streamlit Dashboard

A Streamlit application is used to provide an interactive interface for exploring the results.

## 📊 Dashboard Pages
